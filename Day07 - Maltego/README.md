## Day 7 – Maltego

### Tool Name

**Maltego**

### Category

OSINT (Open Source Intelligence) / Link Analysis / Reconnaissance

### Developer

Paterva

### Overview

**Maltego** is a powerful OSINT and link analysis tool used to **map relationships between data points** such as people, domains, emails, companies, and infrastructure.

Instead of showing raw data in lists, Maltego presents information as **interactive graphs**, making it easier to understand connections and hidden patterns.

It uses “transforms” (automated queries) to pull data from multiple sources and **expand investigations visually**.

### Primary Purpose

The primary purpose of Maltego is to **analyze and visualize relationships between entities** to uncover hidden connections during investigations.

### Key Features

* Graph-based **visual link analysis**
* Uses **transforms** to gather data automatically
* Maps relationships between **domains, emails, IPs, people, organizations**
* Integrates with multiple **OSINT data sources**
* Scalable from small to large investigations
* Custom transform support
* Intuitive drag-and-drop interface
  
### How It Is Used in Cybersecurity

Maltego is widely used in **reconnaissance, threat intelligence, and investigations**.

Some common uses include:

* Mapping an organization’s **digital footprint**
* Linking **emails, domains, and infrastructure**
* Investigating **cybercriminal networks**
* Performing **social engineering intelligence (authorized use)**
* Analyzing relationships in **phishing campaigns**
* Supporting law enforcement and intelligence analysis

It helps answer questions like:
**“How are these entities connected?”**
### Why Beginners Should Know This Tool

Maltego is extremely useful because it changes how you **see data**.

It helps beginners:

* Understand **relationship mapping in cybersecurity**
* Learn visual investigation techniques
* Discover connections that are hard to spot in raw data
* Improve OSINT and analytical thinking skills
* Gain experience with professional investigation tools
