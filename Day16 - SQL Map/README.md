## Day 16 – SQLMap

### Tool Name

**SQLMap**

### Category

Web Application Security / Exploitation Tool

### Developer

Miroslav Stampar

### Overview

**SQLMap** is an open-source tool used to **detect and exploit SQL injection vulnerabilities** in web applications.

It automates the process of identifying vulnerable parameters in a website and can go further to **extract database information, dump data, and even gain deeper access** depending on the vulnerability.

In simple terms, SQLMap turns a manual, complex attack into a **mostly automated process**.

### Primary Purpose

The primary purpose of SQLMap is to **identify and exploit SQL injection flaws in web applications**.

### Key Features

* Automatic detection of **SQL injection vulnerabilities**
* Supports multiple database systems (MySQL, PostgreSQL, Oracle, MSSQL, etc.)
* **Database enumeration** (tables, columns, users)
* Ability to **dump database contents**
* Supports **cookie, header, and POST data testing**
* Can bypass some **WAF protections**
* File system access and OS command execution (in some cases)
* Highly customizable command-line options

### How It Is Used in Cybersecurity

SQLMap is used in **web application penetration testing**.

Some common uses include:

* Detecting **SQL injection vulnerabilities**
* Extracting sensitive **database information**
* Testing input fields for **security weaknesses**
* Validating web application security
* Demonstrating real-world impact of vulnerabilities
* Supporting bug bounty and pentesting workflows

It helps answer:
**“Can this website’s database be accessed or manipulated?”**

### Why Beginners Should Know This Tool

SQLMap is important because SQL injection is still a **common and critical vulnerability**.

It helps beginners:

* Understand how **SQL injection works in practice**
* Learn automated exploitation techniques
* Practice testing web applications safely
* Gain insight into **database security risks**
* Build skills for **web pentesting and bug bounty hunting**
