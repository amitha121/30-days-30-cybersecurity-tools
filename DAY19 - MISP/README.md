## Day 19 – MISP (Malware Information Sharing Platform)

### Tool Name

**MISP (Malware Information Sharing Platform)**

### Category

Threat Intelligence / Threat Sharing Platform

### Developer

CIRCL

### Overview

**MISP (Malware Information Sharing Platform)** is an open-source **threat intelligence platform** used to **collect, store, analyze, and share Indicators of Compromise (IOCs)** and other cyber threat information.

It enables organizations, CERTs, and security teams to collaborate by sharing intelligence about **malware, phishing campaigns, attacker infrastructure, vulnerabilities, and ongoing threats**.

MISP helps security teams respond to attacks faster by making threat information easily searchable and shareable.

### Primary Purpose

The primary purpose of MISP is to **share and manage threat intelligence to improve cyber defense and incident response**.

### Key Features

* Stores and shares **Indicators of Compromise (IOCs)**
* Centralized **threat intelligence repository**
* Supports **STIX, TAXII, and other threat intelligence standards**
* Event-based threat tracking and collaboration
* API support for automation and integrations
* Integrates with SIEMs, EDRs, and security tools
* Community-driven threat intelligence sharing

### How It Is Used in Cybersecurity

MISP is widely used in **threat intelligence and security operations**.

Some common uses include:

* Sharing **IOCs** across organizations
* Tracking **malware campaigns and phishing attacks**
* Enriching alerts in SIEM platforms
* Supporting **incident response investigations**
* Correlating threat data from multiple sources
* Automating threat intelligence workflows

It helps answer:
**“Has this IP, domain, file hash, or URL been associated with known cyber threats?”**

### Why Beginners Should Know This Tool

MISP is valuable because **threat intelligence is a key part of modern cybersecurity**.

It helps beginners:

* Understand how **IOCs are collected and shared**
* Learn the basics of **threat intelligence**
* Explore real-world attack data
* Gain experience with collaborative security platforms
* Build skills relevant to **SOC Analyst and Threat Intelligence roles**
