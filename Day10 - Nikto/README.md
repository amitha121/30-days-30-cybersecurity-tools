## Day 10 – Nikto

### Tool Name

**Nikto**

### Category

Web Vulnerability Scanner / Reconnaissance

### Developer

CIRT.net

### Overview

**Nikto** is an open-source **web server scanner** used to identify **vulnerabilities, misconfigurations, and outdated software** on web servers.

It scans targets against a large database of known issues, including **dangerous files, insecure configurations, and outdated server components**.

Nikto is straightforward and effective—it doesn’t try to be stealthy. It’s designed to **quickly reveal obvious weaknesses**.

### Primary Purpose

The primary purpose of Nikto is to **scan web servers for known vulnerabilities and security issues**.

### Key Features

* Detects **outdated server software**
* Finds **dangerous files and directories**
* Checks for **misconfigurations**
* Scans for **known vulnerabilities (CVEs)**
* Supports SSL/TLS testing
* Fast and easy-to-use command-line tool
* Regularly updated vulnerability database

### How It Is Used in Cybersecurity

Nikto is mainly used during **web application reconnaissance and vulnerability assessment**.

Some common uses include:

* Identifying **weak or outdated web servers**
* Finding exposed **admin panels or sensitive files**
* Detecting **default configurations**
* Checking for insecure server settings
* Supporting penetration testing workflows
* Quickly assessing a target’s basic security posture

It helps answer questions like:
**“What obvious web server issues exist here?”**

### Why Beginners Should Know This Tool

Nikto is great for beginners because it gives **quick, real-world results**.

It helps beginners:

* Understand **common web server vulnerabilities**
* Learn how misconfigurations create risks
* Practice **web security testing basics**
* Get hands-on with scanning tools
* Build a foundation for advanced web testing
