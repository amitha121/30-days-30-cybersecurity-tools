## Day 17 – WhatWeb

### Tool Name

**WhatWeb**

### Category

Web Reconnaissance / Fingerprinting Tool

### Developer

Andrew Horton

### Overview

**WhatWeb** is an open-source tool used to **identify technologies used by websites**.

It performs **web fingerprinting**, meaning it analyzes a website to detect details like the **CMS (WordPress, Joomla), frameworks, server type, analytics tools, and plugins**.

WhatWeb uses a large set of plugins to recognize patterns and signatures, giving a clear picture of **what powers a target website**.

### Primary Purpose

The primary purpose of WhatWeb is to **fingerprint websites and identify underlying technologies**.

### Key Features

* Detects **CMS, frameworks, and web technologies**
* Identifies **server software and configurations**
* Plugin-based detection system
* Supports **aggressive and stealth scanning modes**
* Outputs results in multiple formats (brief, verbose, JSON)
* Can analyze multiple targets at once
* Lightweight and command-line based

### How It Is Used in Cybersecurity

WhatWeb is mainly used during **reconnaissance in web application testing**.

Some common uses include:

* Identifying **technologies used by a website**
* Detecting **outdated CMS or plugins**
* Mapping potential **attack vectors**
* Gathering information before vulnerability scanning
* Supporting penetration testing workflows

It helps answer:
**“What is this website built with?”**

### Why Beginners Should Know This Tool

WhatWeb is important because **knowing the technology stack is step one in attacking or defending a web app**.

It helps beginners:

* Understand **web technologies in real environments**
* Learn how attackers gather initial information
* Practice **web reconnaissance techniques**
* Identify potential weaknesses based on tech stack
* Build a strong foundation in web security
