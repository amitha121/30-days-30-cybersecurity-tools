# Day 3 – Internet Archive (Archive.org)

## 🛠 Tool Name
**Internet Archive (Archive.org)**

## 📂 Category
OSINT (Open Source Intelligence) / Digital Archive

## 👨‍💻 Developer
Internet Archive

## 📖 Overview
Internet Archive (Archive.org) is a massive digital library that stores snapshots of websites, books, media, and historical data.

Its most famous feature, the **Wayback Machine**, allows users to view past versions of websites, sometimes going back decades.

Instead of just seeing what a site looks like today, you can travel back in time and analyze how it changed—content, design, ownership, and even deleted pages.

## 🎯 Primary Purpose
The primary purpose of Archive.org is to preserve digital content and provide historical access to publicly available information on the internet.

## ⚙️ Key Features
- Access to archived versions of websites (Wayback Machine)  
- Huge collection of books, videos, audio, and software  
- View deleted or changed web pages  
- Timeline-based browsing of website history  
- Free and publicly accessible  
- Useful for tracking content changes over time  

## 🔐 How It Is Used in Cybersecurity
Security professionals use Archive.org mainly during reconnaissance and investigation.

### Common Use Cases:
- Finding old or hidden pages that are no longer live  
- Discovering exposed sensitive information from past versions  
- Tracking changes in company infrastructure or domains  
- Identifying previous technologies, APIs, or endpoints  
- Investigating phishing or scam websites history  
- Analyzing how a target evolved over time
