## Day 26 – Ghidra

### Tool Name

**Ghidra**

### Category

Reverse Engineering / Malware Analysis

### Developer

National Security Agency

### Overview

**Ghidra** is a powerful open-source **reverse engineering tool** used to analyze compiled programs and understand how they work internally.

It allows users to **decompile binary code into a more readable form**, helping analysts study software behavior without access to the original source code.

Ghidra is widely used for **malware analysis, vulnerability research, and software auditing**.

### Primary Purpose

The primary purpose of Ghidra is to **reverse engineer compiled software to understand its functionality and identify potential threats or vulnerabilities**.

### Key Features

* Converts **binary code into readable pseudo-code (decompiler)**
* Advanced **disassembly and code analysis**
* Supports multiple architectures (x86, ARM, etc.)
* Function graph visualization
* Powerful scripting support (Python/Java)
* Collaborative analysis features
* Plugin-based extensibility
* Cross-platform (Windows, Linux, macOS)

### How It Is Used in Cybersecurity

Ghidra is heavily used in **reverse engineering and malware analysis**.

Some common uses include:

* Analyzing **malware behavior and payloads**
* Reverse engineering suspicious programs
* Identifying **hidden functionality or backdoors**
* Discovering **software vulnerabilities**
* Studying exploit techniques
* Supporting incident response and threat intelligence

It helps answer:
**“What does this program actually do under the hood?”**

### Why Beginners Should Know This Tool

Ghidra is important because reverse engineering is a **high-value cybersecurity skill**.

It helps beginners:

* Understand how software works at a **low level**
* Learn basics of **assembly and binary analysis**
* Explore malware safely in controlled environments
* Build skills in **advanced security research**
* Prepare for roles in **malware analysis and vulnerability research**
