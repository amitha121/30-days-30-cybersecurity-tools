# 30-days-30-cybersecurity-tools
30-day hands-on cybersecurity challenge: exploring 30 tools for reconnaissance, penetration testing, network security, and digital forensics with practical demos and lab environments.

This repository documents my 30 Days, 30 Cybersecurity Tools challenge, where I explore one cybersecurity tool per day, from network scanning and vulnerability assessment to penetration testing and digital forensics. Each tool includes installation, usage examples, and safe lab demonstrations. The goal is to showcase practical skills, understanding, and consistency, making this a portfolio-ready resource for recruiters and cybersecurity enthusiasts.
