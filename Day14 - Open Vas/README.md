## Day 14 – OpenVAS

### Tool Name

**OpenVAS (Open Vulnerability Assessment System)**

### Category

Vulnerability Scanner / Security Assessment

### Developer

Greenbone Networks

### Overview

**OpenVAS** is a powerful open-source **vulnerability scanning and management tool** used to detect security issues in systems and networks.

It is part of the **Greenbone Vulnerability Management** framework and includes a large, frequently updated database of vulnerability tests.

OpenVAS scans targets for **known vulnerabilities, misconfigurations, and outdated software**, providing detailed reports to help fix security issues.

### Primary Purpose

The primary purpose of OpenVAS is to **identify and manage vulnerabilities in networks, systems, and applications**.

### Key Features

* Comprehensive **vulnerability scanning**
* Large and regularly updated **vulnerability database (NVTs)**
* Detects **CVEs, misconfigurations, and security flaws**
* Web-based interface (Greenbone Security Assistant)
* Detailed reports with **risk levels and remediation advice**
* Supports authenticated and unauthenticated scans
* Scheduling and automation capabilities
* Fully open-source solution

### How It Is Used in Cybersecurity

OpenVAS is widely used in **vulnerability management and security auditing**.

Some common uses include:

* Scanning networks for **known vulnerabilities**
* Identifying **unpatched systems**
* Assessing overall **security posture**
* Supporting compliance and security standards
* Prioritizing risks based on severity
* Assisting penetration testers in identifying weaknesses

It helps answer:
**“Where are the security gaps in this system?”**

### Why Beginners Should Know This Tool

OpenVAS is important because it provides **enterprise-level scanning for free**.

It helps beginners:

* Learn **vulnerability scanning concepts**
* Understand how real-world security issues are detected
* Practice analyzing **scan reports and risk levels**
* Gain experience with professional security tools
* Build skills in **vulnerability management**
