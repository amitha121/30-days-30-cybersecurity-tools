## Day 13 – Angry IP Scanner

### Tool Name

**Angry IP Scanner**

### Category

Network Scanning / IP Scanning

### Developer

Anton Keks
### Overview

**Angry IP Scanner** is a fast and lightweight tool used to **scan IP addresses and ports** across a network.

It works by pinging a range of IP addresses to identify **active hosts**, and then optionally checks for **open ports, hostnames, and services**.

Unlike more advanced tools like Nmap, Angry IP Scanner focuses on **speed and simplicity**, making it ideal for quick network scans.

### Primary Purpose

The primary purpose of Angry IP Scanner is to **quickly identify active devices and open ports on a network**.

### Key Features

* Fast scanning of **IP ranges and subnets**
* Detects **live hosts (active devices)**
* Shows **open ports and services**
* Resolves **hostnames and MAC addresses**
* Simple and easy-to-use **graphical interface**
* Exports scan results (CSV, TXT, etc.)
* Cross-platform (Windows, Linux, macOS)
* No installation required (portable version available)

### How It Is Used in Cybersecurity

Angry IP Scanner is commonly used in **network reconnaissance and monitoring**.

Some common uses include:

* Discovering **devices on a network**
* Identifying **unauthorized or unknown systems**
* Checking for **open ports on hosts**
* Performing quick **internal network scans**
* Assisting in network troubleshooting
* Supporting initial stages of penetration testing

It helps answer:
**“What devices are active on this network?”**
### Why Beginners Should Know This Tool

Angry IP Scanner is perfect for beginners because it’s **simple but practical**.

It helps beginners:

* Understand **network scanning basics**
* Learn how devices appear on a network
* Practice identifying **active hosts and services**
* Gain quick results without complex commands
* Build a foundation before using advanced tools like Nmap
