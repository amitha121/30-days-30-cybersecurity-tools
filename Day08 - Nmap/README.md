## Day 8 – Nmap

### Tool Name

**Nmap (Network Mapper)**

### Category

Network Scanning / Reconnaissance / Security Auditing

### Developer

Gordon Lyon

### Overview

**Nmap** (Network Mapper) is one of the most widely used tools in cybersecurity for **discovering hosts and services on a network**.

It sends specially crafted packets to target systems and analyzes their responses to determine **open ports, running services, operating systems, and potential vulnerabilities**.

Nmap is fast, flexible, and powerful—used by both defenders and attackers to **map networks and identify entry points**.


### Primary Purpose

The primary purpose of Nmap is to **scan networks and identify open ports, services, and system details** for security assessment.

### Key Features

* Detects **live hosts on a network**
* Identifies **open and closed ports**
* Service and **version detection**
* **Operating system detection**
* Scriptable using **Nmap Scripting Engine (NSE)**
* Supports stealth scanning techniques
* Can perform **vulnerability scanning (via scripts)**
* Works on Windows, Linux, and macOS

---

### How It Is Used in Cybersecurity

Nmap is a core tool in **reconnaissance and security auditing**.

Some common uses include:

* Mapping a network’s **attack surface**
* Identifying **open ports and exposed services**
* Detecting **outdated or vulnerable software**
* Performing **internal and external network scans**
* Verifying firewall and security configurations
* Supporting penetration testing workflows

It helps answer questions like:
**“What’s open, and what can I potentially exploit?”**

### Why Beginners Should Know This Tool

Nmap is a **must-learn tool** in cybersecurity—no shortcuts here.

It helps beginners:

* Understand **network structure and communication**
* Learn how systems expose services
* Practice **real-world scanning techniques**
* Build a foundation for penetration testing
* Get comfortable with command-line security tools
