## Day 6 – Shodan

### Tool Name

**Shodan**

### Category

OSINT (Open Source Intelligence) / Cyber Reconnaissance / Search Engine

### Developer

John Matherly

### Overview

kNJ?purpose=fullsize)

**Shodan** is a specialized search engine that indexes **internet-connected devices** instead of websites.

While normal search engines like Google index web pages, Shodan scans the internet to find **servers, routers, webcams, IoT devices, databases, and industrial systems**—and shows their exposed information.

It reveals what devices are publicly accessible and **how they are configured**, which can include banners, open ports, software versions, and sometimes even sensitive data.

### Primary Purpose

The primary purpose of Shodan is to **discover and analyze internet-exposed devices and services** across the globe.

### Key Features

* Search for **internet-connected devices (IoT, servers, cameras, etc.)**
* Displays **open ports and services**
* Shows **software versions and banners**
* Advanced filters (location, organization, port, OS)
* Tracks **vulnerabilities and exposed systems**
* Real-time and historical data access
* API support for automation

### How It Is Used in Cybersecurity

Shodan is heavily used during **reconnaissance and threat intelligence gathering**.

Some common uses include:

* Identifying **exposed servers and services**
* Detecting **misconfigured systems**
* Finding **unsecured IoT devices**
* Monitoring **attack surface of organizations**
* Discovering systems vulnerable to known exploits
* Tracking **global cybersecurity trends**

It can answer questions like:
**“What devices of this company are exposed to the internet?”**

### Why Beginners Should Know This Tool

Shodan is eye-opening because it shows **how much of the internet is exposed and searchable**.

It helps beginners:

* Understand **real-world exposure risks**
* Learn how attackers find targets quickly
* Explore **internet-wide reconnaissance techniques**
* Gain awareness of **misconfigurations and vulnerabilities**
* Build strong OSINT and security analysis skills
