## Day 21 – Snort

### Tool Name

**Snort**

### Category

Network Security / Intrusion Detection & Prevention System (IDS/IPS)

### Developer

Cisco Systems

### Overview

**Snort** is a powerful open-source tool used for **real-time network intrusion detection and prevention**.

It monitors network traffic and analyzes packets to detect **malicious activity, attacks, or policy violations** using predefined or custom rules.

Snort can operate in different modes—**sniffer, packet logger, and intrusion detection/prevention**—making it highly flexible for network security.

### Primary Purpose

The primary purpose of Snort is to **detect and prevent suspicious or malicious activity on a network**.

### Key Features
* Real-time **packet analysis and traffic monitoring**
* Rule-based **intrusion detection engine**
* Detects attacks like **port scans, DoS, exploits, malware traffic**
* Supports **custom rule creation**
* Can operate as **IDS (alerting)** or **IPS (blocking)**
* Packet logging for forensic analysis
* Protocol analysis (TCP/IP, HTTP, DNS, etc.)
* Open-source and widely supported
### How It Is Used in Cybersecurity

Snort is widely used in **network security monitoring and threat detection**.

Some common uses include:

* Detecting **intrusion attempts and attacks**
* Monitoring network traffic for **suspicious behavior**
* Blocking malicious traffic (in IPS mode)
* Identifying **known exploit signatures**
* Supporting incident response and investigations
* Enhancing network defense in SOC environments

It helps answer:
**“Is someone attacking or abusing this network?”**

### Why Beginners Should Know This Tool

Snort is essential because **detection is a core part of cybersecurity**.

It helps beginners:

* Understand how **network attacks are detected**
* Learn rule-based security systems
* Gain experience with **IDS/IPS concepts**
* Analyze real network traffic for threats
* Build skills relevant to **SOC and blue team roles**
